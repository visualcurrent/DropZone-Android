# UNINSTALL — reclaiming the space used by the Android build toolchain

Everything installed to build the APK is listed here. Nothing was added to the system PATH, the registry, or Windows features, and no installer was run; every item is a plain folder. The agent deleted none of it; removal is yours.

> [!warning] Effect of removing the toolchain
> `build.bat` stops working until the toolchain is put back. The debug signing key lives inside it (`android-user-home\debug.keystore`); an APK built with a new key will not install over the old app, so the old app must be uninstalled from each phone first (which also clears its log).

## 1. Close anything holding the files
Run in a terminal. `adb kill-server` stops the background adb process; the second line lists any leftover emulator or Java process (expect no output).

```bat
C:\adb\adb.exe kill-server
tasklist | findstr /I "qemu emulator java.exe"
```

## 2. Folders to remove

| Folder | What it is | Size |
|---|---|---|
| `D:\AndroidToolchain` | JDK 17, Gradle, Android SDK, emulator and its Android 15 image, Gradle download cache, debug signing key, the downloaded zips | 8.8 GB (measured 2026-11-11) |
| `D:\AI-dev\PROJECTS\DropZone-Android\app\build`, `\build`, `\.gradle` | build output, regenerated by `build.bat` | small |
| `C:\Users\Gabe\AppData\Local\Temp\claude\a4cb7e48a29f9031` | the agent's scratch folder, including multi-GB test files | several GB |
| `C:\Users\Gabe\AppData\Local\Temp\dzchk` | one extracted APK asset used for a check | under 1 MB |
| `C:\Users\Gabe\.android` | NOT from this work: created 2025-09-26 by your existing adb. Keep it. The emulator may have added a small settings file inside. | small |

Check the real sizes before deciding (read-only):

```powershell
"{0:N1} GB" -f ((Get-ChildItem 'D:\AndroidToolchain' -Recurse -File | Measure-Object Length -Sum).Sum / 1GB)
```

A middle option that keeps the build working: remove only `D:\AndroidToolchain\downloads` (the zips, already unpacked), `D:\AndroidToolchain\sdk\system-images` and `D:\AndroidToolchain\sdk\emulator` (only needed for emulator testing).

## 3. On the phones
Uninstall "DropZone" like any app, or `C:\adb\adb.exe uninstall com.visualcurrent.dropzone`. This removes the app, its log, and any files still shared.
